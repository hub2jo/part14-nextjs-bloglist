# Blog app

A small blog application built during the **Full Stack Open** Next.js course.

## What you can do

- Browse all blogs and search them by title
- Like the blogs you enjoy
- Register, log in, and add your own blogs
- Keep a personal reading list on your [own page](/me)

## Built with

1. Next.js App Router with Server Components and Server Actions
2. Drizzle ORM on a Neon Postgres database
3. NextAuth for authentication
4. Tailwind CSS for styling
